# Hazidien Ramadhan Utomo — Portfolio

A simple, accessible portfolio for Hazidien's GIS, mapping and spatial-planning work. It uses static HTML and CSS and can be hosted with GitHub Pages.

## Preview locally

Open `index.html` in a browser, or run a local web server from the project folder:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and the root folder (`/`). GitHub Pages will publish the static site.

## Main files

- `index.html` — all portfolio content and project links
- `style.css` — layout, colors, typography and responsive behavior
- `assets/profile.jpg` — profile photo
- `assets/cv.pdf` — CV download
- `assets/portfolio.pdf` — full portfolio download
- `assets/projects/solar-surabaya.webp` — rooftop solar analysis map
- `assets/projects/deforestation-west-sumatra.webp` — forest-change map
- `assets/projects/campus-transit.webp` — campus transit map
