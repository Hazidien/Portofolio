# Hazidien Ramadhan Utomo — GIS & Spatial Portfolio

A lightweight, responsive portfolio website presenting GIS, remote sensing, spatial planning and WebGIS work in plain language.

## Run locally
Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages
In **Settings → Pages**, choose **Deploy from a branch**, select `main` (or the redesign branch while previewing) and the root folder `/`.

## Structure
- `index.html` — page structure and profile content
- `style.css` — responsive layout and visual styles
- `script.js` — project filtering, project detail dialogs and mobile navigation
- `assets/` — profile photo, project images, CV, portfolio PDF, certificates and software logos

## Notes
- The redesign is being built in this repository only. The original `Hazidien/hazidien-portfolio` repository is not modified.
- Project cards are explained in everyday language, with the technical approach and tools available when a card is opened.
- Codespaces-based demos may be offline when their backend is not running.
